# Release 0.23.2

This release aligns the deletion contract with legacy GenroPy JavaScript.

## Detachment

- `pop`, `pop_node` and the silent `clear` notify delete subscribers while the
  removed nodes still reference their containing Bag. Subscribers can reach
  the removed node's ancestors, as they can in the legacy JavaScript Bag. The
  containing-Bag reference is cleared once the subscribers have run.
- `BagNodeContainer.pop` and `BagNodeContainer.clear` no longer detach the
  removed nodes themselves; the owning Bag does it after notification.

## Fixes

- `BagNode.parent_node` and `BagNode.get_inherited_attributes` test the
  containing Bag against `None` instead of relying on its truthiness. A node
  removed from a Bag that became empty reported no parent node.

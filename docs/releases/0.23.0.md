# Release 0.23.0

This release makes Bag and its resolvers synchronous and adds compatibility for
selected historical GenroPy consumers. It does not install the GenroPy
implementation switch; that integration is a separate framework change.

## Breaking changes

- Resolver loads and callbacks execute synchronously on the caller's stack.
  There is no automatic event-loop or threadpool dispatch.
- Async callbacks, awaitable results and async-only resolver implementations
  raise explicit errors. `BagAsyncCbResolver` remains an importable migration
  error, not an asynchronous implementation.
- Automatic `interval` refresh is no longer supported. Schedule external work
  in the application and explicitly update or refresh Bag values.
- HTTP resolvers use a synchronous client. Code running in an event loop must
  account for blocking I/O; Bag does not move that work to another thread.
- A list of `(label, value)` or `(label, value, attributes)` tuples now creates
  named nodes. To store such a tuple as a positional value, provide an explicit
  mapping, for example `Bag({'0': ('label', value)})`.

## Construction and compatibility

- Single node tuples and sequences of node tuples support named values and
  attributes. Attribute mappings are copied; invalid attributes preserve
  `fill_from` atomicity. Ordinary lists and lists of lists remain positional.
- Existing directory paths, including `pathlib.Path`, mount a lazy
  DirectoryResolver under the directory basename. Nested directories and XML
  files load synchronously on demand.
- Selected historical camel-case methods and signatures are provided on the
  actual Bag, BagNode and BagResolver classes. Application subclasses retain
  the same base-class identity.
- Added or corrected node lookup, menu row construction, merge/traversal,
  formatting, legacy keyword handling, legacy XML wire encoding and pickle
  behavior used by the GenroPy integration.
- `getNodeByAttr` searches loaded values without expanding lazy hierarchical
  data. The snake-case query keeps its existing behavior.
- Pickled runtime state omits transient subscribers and parent links, with
  back-reference restoration on loading. Legacy mutating preparation/restoration
  methods remain distinct from normal nonmutating serialization.
- Reactive synchronous refresh occurs after node attributes have been updated.

## Scope and migration

This is bounded compatibility, not complete equivalence with the historical
GenroPy Bag. Formula/validation/diff APIs and automatic asynchronous behavior
are not restored. The constructor does not accept `_template_kwargs`; callers
must perform intended template substitution themselves. The historical
misspelling `_template_kargs` is ignored when a source is supplied.

Use the matching GenroPy integration and its explicit
`implementation="genro-bag"` setting to replace historical imports in that
framework. Installing this package alone does not modify GenroPy imports.
